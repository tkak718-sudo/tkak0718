# 問い合わせフォームの自動入力・自動送信

`新規クライアント_100社_フォーム可_20260806.csv` のようなCSVを読み、各社のフォームを開いて自動入力し、送信まで行う。

**既定は下見（dry-run）で、送信しない。** 送信するには `--send` と `--yes` の両方が要る。

## 準備

御社のPCで動かす。ブラウザを実際に起動するため、社内プロキシがある環境では通らないことがある。

```
pip install playwright
playwright install chromium
```

`profile.example.json` をコピーして `profile.json` を作り、送信者情報と本文を書き換える。
本文の `{会社名}` はCSVの会社名に置き換わる。

## 使い方

```bash
# 1. まず下見。何がどう入るかをスクリーンショットとCSVで確認する（送信しない）
python form_bot.py --csv ../新規クライアント_100社_フォーム可_20260806.csv --profile profile.json

# 2. 自社のフォームに1件だけ通して、本文と項目対応を目で確かめる
python form_bot.py --csv ../新規クライアント_100社_フォーム可_20260806.csv --profile profile.json \
       --test-url https://自社サイト/contact --send --yes

# 3. 本番。まずは少数で
python form_bot.py --csv ../新規クライアント_100社_フォーム可_20260806.csv --profile profile.json \
       --send --yes --limit 10 --interval 60
```

`--headed` を付けるとブラウザが見えるので、最初はこれで様子を見るとよい。

## 誤送信を防ぐ仕掛け

意図せず送ってしまう事故は、原因ごとに別々の歯止めを置いてある。

| 事故 | 歯止め |
|---|---|
| 確認のつもりが送信していた | **既定が下見。`--send` と `--yes` の二重フラグがないと送信処理に入らない** |
| 同じ相手に二度送る | **送信済み台帳**（`sent_ledger.jsonl`）。会社名＋ドメインのハッシュで判定し、送信の**直前**に `submitting` を書くので、途中で落ちても再送しない |
| 営業お断りの相手に送る | ページ本文を読み、「営業・勧誘…お断り／ご遠慮／受け付けておりません」を検出したら**除外**。オプションで無効化できない |
| 採用・サポート窓口に送る | 「採用専用」「サポート専用」「取材専用」の文言とURL（`recruit` `saiyo` `support` など）を検出して除外 |
| CAPTCHAを突破しようとする | reCAPTCHA/hCaptcha/Turnstile を検出したら**送信せず除外**。回避処理は入れていない |
| 「確認する」ボタンを送信と誤認 | 確認ボタンと送信ボタンを別々のパターンで探し、確認語しか含まないボタンは送信候補から外す。日本のフォームは確認画面を挟むものが多い（検証した30社中6社） |
| 項目がずれたまま送る | 必須項目が1つでも埋まらなければ**中止**。埋まった項目数が `--min-fields`（既定3）未満でも中止 |
| 想定外の本文で大量送信 | `--limit`（既定20件）と `--interval`（既定45秒）。一度に走る数と間隔を必ず通る |
| 何を送ったか分からなくなる | 全件スクリーンショット（`shots/`）と、入力内容つきの結果CSV |
| 同意チェックの取り違え | 「同意・承諾・プライバシー」を含むチェックボックスだけ入れる。メルマガ購読などは触らない |

## 実フォームでの検証結果

配布した100社のうち先頭30社で判定ロジックを確認した（取得のみ・送信なし）。

- `<form>` 検出 21 / CAPTCHA 4 / 到達不可 2 / 確認画面あり 6
- 項目分類のヒット：メール15、電話12、氏名10、フリガナ8、本文8、会社名6（`name`と`placeholder`だけの下限値。実行時はラベルも見る）
- 確認／送信ボタンの判定 8ケース全て正しく分離
- 営業お断り文言の検出 5ケース全て正しく判定

`python selftest.py` で再実行できる。

## 出力

- `result.csv` — 会社名／結果／理由／入力内容／スクリーンショットのパス／時刻
- `sent_ledger.jsonl` — 送信済み台帳。**消さないこと。** 消すと二重送信の歯止めが外れる
- `shots/` — 入力後と送信後の画面

結果の `unknown` は「送信はしたが完了表示を確認できなかった」もの。スクリーンショットを見て判断する。

## 運用上の注意

- フォーム営業は違法ではないが、[特定電子メール法](https://media.smart-sales.ai/article/btob-2fd65042)のグレーゾーンにあたるとする解釈がある。配布リストの主力は公益財団法人・自治体外郭団体で、営業利用を想定していない窓口が多い
- 本文に**連絡停止の導線**を必ず入れる（`profile.example.json` の本文に入れてある）
- 返信で停止を求められたら、その会社をCSVから外す
- `--interval` を短くしすぎない。相手のサーバーにも自社の評判にも響く
