# 使い方

コマンドを打つ必要はありません。**`.bat` ファイルをダブルクリックするだけ**です。
番号の順に実行してください。

> ## スマートアプリコントロールで止まる場合
>
> Windows 11 のスマートアプリコントロールは、署名のない `.bat` をブロックします。
> **オフにしないでください。一度オフにすると Windows を再インストールしない限り戻せません。**
>
> `.bat` を使わない手順を `コピペ用コマンド.txt` に用意しました。そちらを使ってください。
> オフにしなくても動きます。

## 置き場所

このフォルダを、デスクトップなど分かりやすい場所に置いてください。
**CSVファイルは1つ上の階層**に置きます。

```
どこか適当なフォルダ/
├── 自動送信対象_77社_20260806.csv     ← ここ
├── 手動対応_23社_20260806.csv
├── 除外リスト_20260806更新版.md
└── form_bot/                          ← このフォルダ
    ├── 0_さいしょに1回だけ_準備.bat
    ├── 1_下見_5社だけ.bat
    ├── 2_下見_ぜんぶ.bat
    ├── 3_テスト送信_自社あて.bat
    ├── 4_本番送信.bat
    ├── 5_除外リストを更新.bat
    ├── form_bot.py
    └── profile.json
```

## 0. 準備（さいしょの1回だけ）

**`0_さいしょに1回だけ_準備.bat` をダブルクリック**

黒い画面が開いて、必要なものを入れます。**5分ほど**かかります。
「準備できました」と出たら閉じてOKです。

> **Pythonが入っていません** と出たら
> https://www.python.org/downloads/ から入れてください。
> インストール中の画面で **「Add Python to PATH」に必ずチェック**を入れてください。
> 入れ終わったら、もう一度このbatを実行します。

---

## 1. 下見（5社だけ・送信されません）

**`1_下見_5社だけ.bat` をダブルクリック**

**ブラウザが自動で開きます。触らずに見ていてください。**
文字が自動で入っていくのが見えます。5社ぶん繰り返して、自動で閉じます。

### 終わったら見るもの

| ファイル | 何が分かるか |
|---|---|
| `result.csv` | どの会社がどうなったか |
| `shots` フォルダ | 入力後の画面の写真 |

**写真で確認すること**

- フリガナの欄に「イシイ タカアキ」が入っているか（**漢字が入っていたら異常**）
- 本文が最後の署名まで入っているか
- 「個人情報の取り扱いに同意する」にチェックが入っているか

おかしいところがあれば、`result.csv` と写真を送ってください。直します。

## 2. 下見（77社ぜんぶ・送信されません）

**`2_下見_ぜんぶ.bat` をダブルクリック**

ブラウザは表示されません。**15分ほど**かかります。放っておいて大丈夫です。

終わったら `result.csv` の**「理由」の列**を見てください。

| 理由の欄 | 意味 |
|---|---|
| **空欄** | 自動で送れます |
| `必須項目が埋まらない` | このフォームは手動で |
| `本文が上限…に収まらない` | このフォームは手動で |

## 3. テスト送信（自社あて・1件だけ）

**`3_テスト送信_自社あて.bat` をダブルクリック**

**ここで初めて実際に送信します。宛先は御社自身のフォームです。**

御社の問い合わせフォームのURLを聞かれるので、貼り付けてEnter。
確認のため「**はい**」と入力するまで送信されません。

### 届いたメールで確認すること

- 改行が崩れていないか
- 返信先が `ishii@active-c.jp` になっているか
- 本文が途中で切れていないか

---

## 4. 本番送信

**`4_本番送信.bat` をダブルクリック**

何社に送るか聞かれます。**最初は 10 と入力**してください。
確認のため「**送信します**」と入力するまで送信されません。

60秒おきに送るので、10社なら10分ほどです。

### 終わったら `result.csv` の「結果」の列

| 結果 | 意味 |
|---|---|
| `sent` | 送信できました |
| `unknown` | 送ったが完了画面を確認できず。**写真を見て判断** |
| `skip` | 送っていません |

**1〜2日おいて、返信や不達がないか確認してから残りを進めてください。**

続きを送るときも、**同じ `4_本番送信.bat` を実行するだけ**です。
一度送った会社は自動で飛ばされます。

## 5. 除外リストを更新

**`5_除外リストを更新.bat` をダブルクリック**

送信した会社が除外リストに入り、次に企業を探すときに同じ相手を拾わなくなります。

---

## 絶対にしないでください

- **`sent_ledger.jsonl` を消さない** — 二重送信を防ぐ唯一のファイルです。フォルダごと移動するときも一緒に
- **`--interval` を短くしない** — batに書いてある60秒を縮めないでください。相手のサーバーにも自社の評判にも響きます
- **返信で「不要」と言われた会社を放置しない** — CSVから削除してください

## 手動対応の23社について

`手動対応_23社_20260806.csv` は自動で送れません。

- 21社は **CAPTCHA**（「私はロボットではありません」の認証）があるため
- 2社は URLが変わっていて到達できないため

札幌市芸術文化財団、千葉県文化振興財団、鼓童など規模の大きい先が多いので、
**むしろ1社ずつ手で書いたほうが通りが良い層**です。

# 送信は人が押す方式（おすすめ）

`--assist` を付けると、**自動で入力したところで止まり、送信ボタンは人が押します。**
一斉送信の事故が構造的に起きません。

```
python form_bot.py --csv "..\自動送信対象_77社_20260806.csv" --profile profile.json --assist
```

## 動き

1. ブラウザが自動で開く（`--headed` は不要。必ず表示されます）
2. フォームに自動で入力される
3. **そこで止まり、黒い画面に会社名と入力内容が出る**
4. ブラウザで内容を確認し、**自分で送信ボタンを押す**
5. 黒い画面に戻って **Enter** → 次の会社へ

黒い画面での操作は3つだけです。

| 入力 | 意味 |
|---|---|
| **Enter** | 送信した。次の会社へ |
| **s** ＋Enter | この会社には送らない。次へ |
| **q** ＋Enter | ここで中断する |

## 確認画面のあるフォーム

`--to-confirm` を足すと、「確認する」ボタンまで自動で進めます。
人がやるのは最後の「送信する」1押しだけになります。

```
python form_bot.py --csv "..\自動送信対象_77社_20260806.csv" --profile profile.json --assist --to-confirm
```

## この方式でも守られること

- CAPTCHAのある会社、営業お断りの会社は**そもそも開きません**（自動と同じ判定）
- 必須項目が埋まらない会社は飛ばします
- Enterを押した会社は**送信済み台帳に記録**されるので、次回は開きません
- 途中で `q` で止めても、そこまでの記録は残ります

**`--assist` と `--send` は同時に使えません。** 人が押す方式と、全自動は排他です。
