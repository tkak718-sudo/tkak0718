================================================================
 スマートアプリコントロールで .bat が使えない場合の手順
================================================================

.bat ファイルは使いません。下のコマンドをコピーして貼り付けます。
スマートアプリコントロールをオフにする必要はありません。


----------------------------------------------------------------
【準備1】Python を Microsoft Store から入れる
----------------------------------------------------------------

  1. スタートボタン → 「Microsoft Store」を開く
  2. 検索欄に  Python 3.12  と入力
  3. 「Python 3.12」（発行元 Python Software Foundation）を「入手」

  ※ python.org からダウンロードした exe はブロックされることがあります。
    Microsoft Store 版は Windows が信頼済みなのでブロックされません。


----------------------------------------------------------------
【準備2】コマンドを打つ画面を開く
----------------------------------------------------------------

  1. form_bot フォルダを開く
  2. フォルダの上部にある「アドレスバー」（フォルダの場所が
     表示されている白い横長の欄）をクリック
  3. そこに書いてある文字を消して  powershell  と入力して Enter

  → 青い画面（PowerShell）が開きます。ここにコマンドを貼り付けます。

  ※ 貼り付けは Ctrl+V、または画面内で右クリック。


----------------------------------------------------------------
【1回だけ】必要な部品を入れる
----------------------------------------------------------------

  下の2行を、1行ずつコピーして貼り付け → Enter

python -m pip install playwright requests

python -m playwright install chromium

  2行目は200MBほどダウンロードします。5分ほどかかります。


----------------------------------------------------------------
【ステップ1】下見・5社だけ（送信されません）
----------------------------------------------------------------

python form_bot.py --csv "..\自動送信対象_77社_20260806.csv" --profile profile.json --headed --limit 5

  → ブラウザが自動で開きます。触らずに見ていてください。
  → 終わると result.csv と shots フォルダができます。


----------------------------------------------------------------
【ステップ2】下見・77社ぜんぶ（送信されません）
----------------------------------------------------------------

python form_bot.py --csv "..\自動送信対象_77社_20260806.csv" --profile profile.json --limit 77

  → 15分ほどかかります。ブラウザは表示されません。


----------------------------------------------------------------
【ステップ3】テスト送信・自社あて1件だけ
----------------------------------------------------------------

  ↓ 下の行の「ここにURL」を、御社のフォームのURLに置き換えてから貼り付け

python form_bot.py --csv "..\自動送信対象_77社_20260806.csv" --profile profile.json --test-url "ここにURL" --send --yes --headed

  ★ ここで初めて実際に送信します。宛先は御社自身です。


----------------------------------------------------------------
【おすすめ】自動入力して、送信は自分で押す
----------------------------------------------------------------

python form_bot.py --csv "..\自動送信対象_77社_20260806.csv" --profile profile.json --assist --to-confirm --limit 5

  → ブラウザが開いて自動入力され、そこで止まります。
  → 内容を確認して、自分で送信ボタンを押してください。
  → 黒い画面に戻って Enter を押すと次の会社へ進みます。

     Enter    … 送信した。次へ
     s ＋Enter … この会社には送らない
     q ＋Enter … 中断する

  ★ 一斉送信の事故が起きません。最初はこの方式を推奨します。


----------------------------------------------------------------
【ステップ4】本番送信・まず10社
----------------------------------------------------------------

python form_bot.py --csv "..\自動送信対象_77社_20260806.csv" --profile profile.json --send --yes --limit 10 --interval 60

  ★ 実際に他社へ送信します。10分ほどかかります。

  続きを送るときは --limit の数字を変えて同じコマンドを実行。
  一度送った会社は自動で飛ばされるので二重送信になりません。


----------------------------------------------------------------
【ステップ5】送信した会社を除外リストに追加
----------------------------------------------------------------

python update_exclusion.py --base "..\除外リスト_20260806更新版.md" --ledger sent_ledger.jsonl --csv "..\新規クライアント_100社_フォーム可_20260806.csv" --out "..\除外リスト_最新.md"


================================================================
 うまくいかないとき
================================================================

「python は認識されていません」
  → 準備1が終わっていません。Microsoft Store 版を入れてください。
    入れた後は PowerShell を閉じて開き直してください。

「そのようなファイルはありません」
  → CSVの置き場所が違います。
    form_bot フォルダの「1つ上」に CSV を置いてください。

赤い文字がたくさん出た
  → 画面を選択してコピーし、そのまま送ってください。


================================================================
 スマートアプリコントロールについて
================================================================

オフにしないでください。
Windows 11 では一度オフにすると、Windows を再インストールしない限り
元に戻せません。セキュリティを恒久的に下げる操作になります。

上の手順なら、オフにしなくても動きます。
コマンドを手で貼り付けて実行する分には、ブロックされません。
