# crowdbasket-CRM

営業リード管理のCRM。単一のHTMLファイルで動作し、データはFirestoreに保存されます。
ビルド手順はありません（外部ライブラリはCDNのFirebaseのみ）。

## 構成

```
crm-deploy/
  index.html          アプリ本体。これ1つで完結
  auth-callback.html  Outlookにサインインしたあと小窓が戻ってくるだけのページ
wrangler.jsonc        配信設定。crm-deploy/ の中身が公開URLの直下になる
package.json          wrangler のバージョンを固定
```

## 更新のしかた

`main` ブランチが公開中の内容です。**`main` を更新すれば自動で公開されます。**

Cloudflare Workers の Workers Builds がこのリポジトリに繋がっており、`main` への
プッシュを検知して `npx wrangler deploy` を実行します。ファイルを手元にダウンロード
したりアップロードしたりする必要はありません。

1. `crm-deploy/index.html` を編集する
2. `main` にプッシュする
3. Cloudflare の「Deployments」タブに新しいバージョンが増えれば完了
4. 公開URLをスーパーリロード（Ctrl+Shift+R / Cmd+Shift+R）して反映を確認する

デプロイしても既存のクライアントデータはFirestore側にあるため消えません。

### 手元からデプロイする場合

自動デプロイを待たずに反映したいときは、リポジトリのルートで実行します。

```
npm install            # 初回のみ
npx wrangler login     # 初回のみ
npm run deploy
```

配信先の Worker 名は `wrangler.jsonc` の `name` で決まります。ここを変えると別の
URLに新しい Worker が作られてしまうため、変更しないでください。

## 主な機能

- 新規クライアント / クライアントデータ / 商談 / タスクの管理
- 企業リストの一括取り込み（貼り付け・.xlsx・.csv）と重複検出
- AI判定：Claude が web検索で各社を調べ、ランク・イベント規模・主催者・
  LINE公式アカウントを判定
  - 画面内から実行する方法（Anthropic APIキーを使用。キーは端末にのみ保存）
  - Claude に調べさせたCSVを取り込む方法（「AI調査用の指示文をコピー」から
    指示文を取得して使う）
- 配信リストのCSV書き出し、配信停止の取り込み
- 問い合わせ返信：Outlookの受信箱から広告・DMを除き、問い合わせにだけ返信の下書きを作る

## 問い合わせ返信（Outlook連携）

サイドバーの「問い合わせ返信」で、受信メールを読んで返信の下書きを作ります。

1. 受信トレイの最新N件を読み込む
2. 広告・DM・自動通知を落とす（送信専用アドレス、`List-Unsubscribe` などのヘッダ、
   件名の型で機械的に落としたあと、残りを Claude が仕分けします）
3. 問い合わせと判断したものにだけ返信文を作る
4. 画面で内容を確認・編集して「Outlookに下書きを保存」
5. **Outlookの下書きフォルダを開いて、送信ボタンは人が押す**

このアプリがOutlookに求める権限は `Mail.ReadWrite`（共有メールボックス用に
`Mail.ReadWrite.Shared`）だけで、**送信権限 `Mail.Send` は要求していません**。
つまり操作ミスやバグでメールが送信されることは、仕組みとして起こりません。

同じメールに何度も下書きを作らないよう、作成済みのメールIDは端末に記録されます。

### 準備：Azure（Microsoft Entra ID）でのアプリ登録

Outlookに接続するには、1回だけアプリ登録が必要です。無料で、発行されるのは
公開前提のIDだけです（秘密鍵は使いません）。

1. [Azureポータル](https://portal.azure.com) →「Microsoft Entra ID」→「アプリの登録」→「新規登録」
2. 名前は任意（例：`crowdbasket-CRM`）。アカウントの種類は「この組織ディレクトリのみに含まれるアカウント」
3. リダイレクトURIで、プラットフォームに **「シングルページ アプリケーション (SPA)」** を選び、
   公開URLの `/auth-callback.html`（例：`https://crowdbasket-crm.example.workers.dev/auth-callback.html`）を入れる
   - 「Web」ではなく必ず **SPA** を選んでください。SPAを選ぶとブラウザから直接
     トークンを取得できるようになります
4. 登録後の「概要」から **アプリケーション (クライアント) ID** と **ディレクトリ (テナント) ID** をコピー
5. 「APIのアクセス許可」→「アクセス許可の追加」→「Microsoft Graph」→
   **「委任されたアクセス許可」** で次の3つを追加する
   - `User.Read`（接続したアカウントの表示用）
   - `Mail.ReadWrite`（メールを読む／下書きを作る）
   - `Mail.ReadWrite.Shared`（共有メールボックスを読む場合のみ）
   - テナントの設定によっては、管理者が「管理者の同意を与えます」を押す必要があります
6. CRMの「問い合わせ返信」→「設定」に、クライアントID・テナントID・
   読み込む共有メールボックスのアドレス・Anthropic APIキー・署名を入れる

サインインの情報はタブを閉じると消えます。設定した値はその端末のブラウザにだけ
保存され、他の担当者の画面には共有されません。

共有メールボックス（`info@` など）を読む場合は、サインインする本人にその
メールボックスへのアクセス権（フルアクセス）が付いている必要があります。

### アプリ登録なしで使う

「メールを貼り付けて作る」を使えば、Outlookと接続しなくても返信文を作れます。
受信したメールを貼り付けると返信文ができるので、コピーしてOutlookに貼り付けます。
この場合もAnthropic APIキーの設定だけは必要です。
